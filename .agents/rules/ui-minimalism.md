# UI Design & Minimalism Rules

1. **Zero Fluff & No Filler Subtitles**:
   - NEVER add explanatory subtitles, helper paragraphs, or descriptive guide text below page titles, card headers, section titles, or buttons.
   - Do NOT add sentences like "Fill in the details below carefully...", "Note: you only need to...", "This step allows you to...", or "The student has been successfully admitted...".

2. **Purely Functional & High Density**:
   - Keep cards, headers, forms, and dialogs clean, compact, and directly usable by teachers and staff.
   - Use clear titles, labels, badges, and icons to convey purpose without verbose explanatory text.

3. **Persistent Invariant**:
   - When creating or modifying any page, modal, stepper, or component in this codebase, always adhere to this minimalism standard without needing explicit reminders.
